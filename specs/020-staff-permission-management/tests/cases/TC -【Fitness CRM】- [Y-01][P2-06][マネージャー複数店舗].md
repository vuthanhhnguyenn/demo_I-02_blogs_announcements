# TC -【Fitness CRM】- [Y-01][P2-06][マネージャー複数店舗]

**Unit 6** — Phase 2 (real-API) test cases for the **Manager multi-store affiliation** change (2026-11-10). One rule followed across four screens: a **Manager**'s 所属店舗 is multi-select and every selected store is a store it manages (管轄店舗 = 所属店舗); every other role keeps one store.

**Scope**: 所属店舗 on `/staffs/create` and `/staffs/[id]/edit`, the role-change reset rule, the request bodies (`storeIds`), the 所属 block on `/staffs/[id]`, the 所属店舗 column / store filter on `/staffs`, and the Manager's edit scope over a multi-store set.

**Out of scope**: everything Units 1–5 already cover that this change does not touch (names, email, 職位 rules, lifecycle actions, sessions); `PUT /admin/staff/{id}/managed-stores` (superseded by `PATCH … storeIds`, no screen drives it); Phase 2 organisation-hierarchy scope (Y-15).
