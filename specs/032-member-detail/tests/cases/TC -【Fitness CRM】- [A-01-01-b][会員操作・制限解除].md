# TC -【Fitness CRM】- [A-01-01-b][会員操作・制限解除]

**Scope (Unit 3 of the [test plan](../test-plan.md))** — the header **会員操作 (⋯)** menu of the member detail screen (`/members/{memberId}`) for a non-withdrawn and a withdrawn member, and the five surfaces behind it or behind the restriction banners / cards: **ゲートストップ設定**, **ゲートストップ解除** (from ステータス変更 **and** the 基本情報 ゲートストップ card), **予約ペナルティ解除** (from the penalty banner), **ブラックリスト登録**, **個人情報削除** (withdrawn header). Includes the role gates and their server-side enforcement, the blockers, the acknowledgement / typed-confirmation guards, the post-success refresh of banner / card / menus, persistence, the audit record each write leaves, the absence of 強制退会 and 再入会, and 1024px layout stress.

**Out of scope for this document** — the ステータス変更 menu and its six surfaces (Unit 2 — this doc only asserts how ゲートストップ解除 is reached and what it does); the display contract of the four banners and of the ゲートストップ card, incl. the HQ-only visibility of the blacklist banner (Unit 1 — this doc asserts only the change a write produces); the 変更履歴 table layout and labels (Unit 10 — this doc only checks that each write left a record); ブラックリスト一覧 / 詳細 (025 — link intent only); the 強制退会 batch (`A-01 FR-016`, server job); `?sheet=` deep links.
