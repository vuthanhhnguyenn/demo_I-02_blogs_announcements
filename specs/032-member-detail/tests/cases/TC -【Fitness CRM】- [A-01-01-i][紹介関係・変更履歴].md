# TC -【Fitness CRM】- [A-01-01-i][紹介関係・変更履歴]

**Scope (Unit 10 of the [test plan](../test-plan.md))** — two tabs of the member detail screen (`/members/{memberId}`): **紹介関係** (`?tab=referral`, `A-01-01-i` / `A-01 FR-S001` — 紹介経由 banner, 紹介者情報, 招待実績, 紹介サマリー and the **ポイント手動返還** dialog, the tab's only write) and **変更履歴** (`?tab=history`, `A-01 FR-003` 変更履歴タブ — the member's audit table). Covers the tab entry / URL sync for these two tabs, every element and state of both tabs, the refund dialog's validation, role gate and real submission, the role and store-scope gates, the real-API baseline (401, out-of-scope, malformed id, persistence), layout at the 1024px floor, and the **audit sweep** (test-plan §5 / SC-005): every write performed by Units 1–4 leaves its record here.

**Out of scope for this document** — the writes themselves (Units 1–4 perform them; this doc only reads their records); the member edit form and the 変更履歴 content of an attribute edit made there (`020-member-form`), except as a data-preparation step for the stress cases; the ポイント履歴 tab's own cases (Unit 7 — only the refund's effect on it is checked here); the destination screens of the referrer / invitee links (link intent + breadcrumb only); the 休会申請 sheet's ポイント値引き返還 checkbox (Unit 2); 称号 / 連携解除 and the member's own referral code (real endpoint fields with no spec or prototype place).
