### ⚠️ Access-denied copy — resolved: generic 403 is intended, not a bug

TC-A-003–007 (this doc) and `[Y-10-B]`'s TC-B-004 originally expected the feature-specific message quoted in the spec ("CRMメンテナンス管理は本部・System 権限のスタッフのみ参照できます。") for denied-role access. **Confirmed by dev, 2026-07-28**: showing the app-wide shared generic 403 page ("このページを表示する権限がありません。必要な場合は管理者にお問い合わせください。") is the intended behavior for this feature — the feature-specific copy in spec/TC is superseded, not a defect. Access itself is still correctly blocked in every case (no data leak). The additional error toast previously noted alongside the 403 page for the Trainer role (TC-A-005) is also confirmed fixed — no longer reproduces.

**Data limitations**:

- Only 7 sample rows exist in the mockup. If the real seed is similarly small and the default page size is 50, multi-page pagination cases (TC-A-034/035) may be unreachable — verify the real seed's row count first and mark those `Block` if so.
- Exact-instant boundary cases (TC-A-015/016/017/018) need a record whose start/end is very close to "now" at the moment of execution — use whichever real seeded record is closest, or accept a small tolerance window; note the actual timestamps used in the case's execution Notes.
- **通知 column is confirmed hidden this phase, by design** (not an open question): the mockup gates it behind `currentPhase === "2"`, and this branch's git history already contains a "hide column 通知" commit — the column is a Phase-2-only feature, not yet built. Mark TC-A-037/038/039 `Block` ("feature not implemented this phase"), not `NG`.
