**Scope**: `/option-discount/create` and `/option-discount/[id]/edit` — one form in two modes, candidates, validation, two-call save, discard dialog, role gating. **Out of scope**: list (G-02-D), detail (G-02-F), option master screens (candidate source only), discount execution on member contracts.

## Test data reference and limitations

Real backend, shared, **no seed reset**. This unit **creates** the fixtures used by G-02-D and G-02-F. Every set is saved as **無効** (turn the switch OFF — the form defaults to 有効). Constituents are pre-existing active FIT365 options A and B (selecting them does not edit them). Extra leftovers from abuse/concurrency cases (S6–S10) stay 無効 and are listed in the TC result notes. Never save a pre-existing set (R1 is read-only).

| Fixture | Content                                                                                                                                                                                                          |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1      | `QA-SET <D>-01 定額` — 定額値引 `330`, 適用条件 同時申込時, 対象オプション = two pre-existing eligible options A + B, 説明 `QA fixture`, ステータス 無効                                                         |
| S2      | `QA-SET <D>-02 定率` — 定率値引 `10`, 適用条件 家族2名以上, options A + B, 説明 empty, 無効                                                                                                                      |
| S3      | `QA-SET <D>-03 ` + full-width characters to exactly 100 characters, 定額値引 `999999`, 適用条件 既存会員も対象, options = up to 6 eligible options (≥ 2), 説明 = 1000 half-width characters with no spaces, 無効 |
| S4      | `QA-SET-<D>-04-<b>x</b><script>alert(1)</script>` padded with `X` to 100 characters, **no spaces**; 説明 `<b>bold</b><script>alert(2)</script>`; 定額値引 `100`; 同時申込時; options A + B; 無効                 |
| S5      | `QA-SET <D>-05 max` — 定額値引 `999999999`, 同時申込時, options A + B, 無効 (if the system refuses 9 digits, see G-02-E TC on the money boundary)                                                                |
| R1      | Pre-existing seeded set 「ロッカー + 水素水 セット (dev)」 (`00000000-0000-7000-8000-000000000501`) — **read-only reference**, never saved or toggled                                                            |

Limitations: server codes `E-SET-002` / `E-SET-004` cannot be triggered from the UI; only their absence as reachable paths is observed. Fewer than two eligible options → every save case is `Block` "no fixture data".
