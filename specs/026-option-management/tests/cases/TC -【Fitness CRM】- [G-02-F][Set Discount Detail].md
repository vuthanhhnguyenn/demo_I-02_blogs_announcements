## Test data reference and limitations

Real backend, shared, **no seed reset**. Reads fixtures S1–S5 created by G-02-E; R1 is a pre-existing set used **read-only**. The status cases activate a fixture and return it to 無効 in the same case. Never toggle R1.

| Fixture | Content                                                                                                                                                                                                          |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| S1      | `QA-SET <D>-01 定額` — 定額値引 `330`, 適用条件 同時申込時, 対象オプション = two pre-existing eligible options A + B, 説明 `QA fixture`, ステータス 無効                                                         |
| S2      | `QA-SET <D>-02 定率` — 定率値引 `10`, 適用条件 家族2名以上, options A + B, 説明 empty, 無効                                                                                                                      |
| S3      | `QA-SET <D>-03 ` + full-width characters to exactly 100 characters, 定額値引 `999999`, 適用条件 既存会員も対象, options = up to 6 eligible options (≥ 2), 説明 = 1000 half-width characters with no spaces, 無効 |
| S4      | `QA-SET-<D>-04-<b>x</b><script>alert(1)</script>` padded with `X` to 100 characters, **no spaces**; 説明 `<b>bold</b><script>alert(2)</script>`; 定額値引 `100`; 同時申込時; options A + B; 無効                 |
| S5      | `QA-SET <D>-05 max` — 定額値引 `999999999`, 同時申込時, options A + B, 無効 (if the system refuses 9 digits, see G-02-E TC on the money boundary)                                                                |
| R1      | Pre-existing seeded set 「ロッカー + 水素水 セット (dev)」 (`00000000-0000-7000-8000-000000000501`) — **read-only reference**, never saved or toggled                                                            |

Limitations: 対象会員数 > 0 and a never-updated set (更新者 `—`) need existing data; if absent those cases are `Block` "no fixture data".
