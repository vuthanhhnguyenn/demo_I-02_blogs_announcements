# Test Cases: Y-04 規約文書管理 (Terms Document List) — Unit 1

> **Screen**: 規約文書管理 — `terms-list.tsx` → `/terms`
> **Feature**: `specs/017-terms-management` · **Plan**: [../test-plan.md](../test-plan.md) (Unit 1 of 5) · **Written**: 2026-10-19
> **Scope**: the list screen only — type tabs, search, brand/status filters, 削除済みも含めて表示, filter banner and 条件をクリア, filtered-empty / true-empty states, pagination (25/50/100), row ⋯ menu, row-level delete with its confirmation dialog, per-role scope and visibility, Trainer no-permission panel, 401 expiry, persistence, layout at 1024px. **Out of scope** (separate units): the detail page (`/terms/[id]`, Unit 2), the create / edit / new-version forms (Units 3–5) — they are only the _navigation targets_ checked here. ## Execution record (2026-10-19)

- **Run by**: Claude (Playwright, headless Chromium). **Single pass.** Viewports: 1440×900 default; **1024×768** for every layout/long-value case; 1600×900 for the wide checks.
- **Backend**: `NEXT_PUBLIC_REAL_API_URL=http://localhost:4000` (local BFF + auth-svc, enrollment-svc, media-svc, contracts-svc started for the run; app `http://localhost:3000`). Cognito password login was rejected by this backend (`E-AUTH-032`), so every account signed in with a **magic link** (link read from the backend log).
- **Re-run 2026-10-20 (upload fixed)**: LocalStack S3 now serves presign/PUT/GET (stub limit **E1** no longer applies; cases re-run are marked `Re-run 2026-10-20` in Notes). Backend `.env` needed `PUBLIC_API_BASE_URL=http://localhost:4000` so `pdfUrl` points at the BFF. Test data created for the re-run (all `ZZQA_`, 49 rows incl. versions) was logically deleted at the end; seed rows untouched.
- **Accounts**: HQ `admin@example.com`, System `crm-system@crm-test.example.com`, Manager `crm-manager@…`, Staff `crm-staff@…`, Observer `crm-observer@…`, Trainer `crm-trainer@…` (all `@crm-test.example.com`). `system@fitness-dx.internal` is refused by the domain allow-list (`E-DMN-007`) and was not used.
- **Environment limits recorded as `Block`**: **E1** — the local presign URL is a non-resolvable stub (`https://media-upload.local/…`); the storage PUT was emulated with a browser-level 200 (the real storage was never reached, so PDF preview/URL, stored file name and size cannot be verified; file names are lost once the never-completed upload session expires). **E2** — each PDF selection creates a pending presign session; a 6th within ~15 min per user returns `429 E-MED-008`. Other `Block`s are data (`data`), tool (`tool`), time (`G3`) or a documented bug (`BUG-xx`).
- **Data left on the backend**: 20 logically-deleted `ZZQA_` rows (see the Unit 3 doc for the list); no live `ZZQA_` row remains; the 8 pre-existing rows were not edited or deleted. Uploaded objects and presign sessions cannot be removed (G1).
