# TC -【Fitness CRM】- [A-03-01][休会・退会申請詳細] (Leave & Withdrawal Application Detail)

**Scope**: Unit 3 of [test-plan.md](../test-plan.md) — the suspension / withdrawal **application detail** at `/members/leaves/[id]?type=suspension|withdrawal`: back link, title + state badge + 個別会費調整中 badge, member head-up card, 申請情報, 承認フロー timeline, 代理申請情報, 関連情報, 休会・退会履歴 strip, sticky status card (退会取り消し / 処理完了 text / 休会中 hand-off) and the detail's own 退会取り消し dialog (`退会を取り消しますか？`).

**Out of scope** (a case may confirm the navigation fires, never the destination): the list 一覧 view and its dialog (Unit 1), 月別ビュー (Unit 2), A-01-01 会員詳細 (target of 会員詳細を開く / 「会員詳細で休会を解除する」; its status-change sheet is used only for data setup), application creation / approval / rejection / 休会 release, the System batches, 臨時休会, the shared header store-scope selector and 「デモ: ユーザー切替」. **Asserted absent**: 変更履歴 tab / `statusHistories` rendering (Q-14), 承認 / 却下 / 復帰処理 / 退会処理を実行 actions, history mutation (FR-074), the application-ID header badge (FR-055) and the 取り消し済み audit block (retired FR-079a).
