# TC -【Fitness CRM】- [A-03][休会・退会管理（一覧）] (Leave & Withdrawal Management — List, 一覧 view)

**Scope**: Unit 1 of [test-plan.md](../test-plan.md) — the 休会・退会管理 list on route `/members/leaves` in the **一覧** view: page header + filtered count, Trainer denial, toolbar (詳細フィルター left, 一覧 / 月別ビュー toggle right — presence/default only), filter panel (種別 / ステータス / 店舗 / ブランド / 予定日), filter-result banner, table (会員ID … 未納金 + row ⋯ menu), pagination footer, empty / loading / error states, and the **退会取り消し dialog** (`退会取り消しを実行しますか？` + 取り消し理由) that exists only in this view.

**Out of scope** (a case may confirm the navigation fires, never the destination's behaviour): 月別ビュー grid / tooltip / 表示 filter (Unit 2), 休会・退会申請詳細 `/members/leaves/[id]` and its own dialog (Unit 3), A-01-01 会員詳細, A-01 / C-01 (data setup only), 臨時休会 `emergency-suspension` (A-03 FR-003), application creation / approval / batch transitions, the header store-scope selector and 「デモ: ユーザー切替」 (preconditions only). SC-009 (100k-row performance) is **not testable** on dev and has no case (N/A).
