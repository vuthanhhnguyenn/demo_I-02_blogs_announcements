# Test Cases: Main Contract List (G-01) — Phase 2 (real API)

> Driven by [test-plan.md](../test-plan.md), unit 1 "Main Contract List". Covers `/contracts` only: the table, search, 詳細フィルター, filter banner, sort, pagination, URL state, the row ⋯ menu with its `contracts/count` probe, and the list delete dialog. **Out of scope** (checked only up to "the right route opens"): 主契約 詳細 `/contracts/[id]`, 新規登録 / 複製 / 子主契約作成 `/contracts/create…`, 編集 `/contracts/[id]/edit` — the form is used only as a setup tool to create fixtures.

## ⚠️ Data-safety rule — read before executing

The dev backend is real, **shared**, and has **no seed reset**.

- **Never edit or delete a master this run did not create** (seed `MC-0001`…`MC-0010`, other testers' rows, integration leftovers). On those rows you may only list, search, filter, sort, click the row, open ⋯ and hover tooltips. Never click `削除` → `削除する` on them, and never open their 編集 form.
- There is no exception: TC-091 (replayed `DELETE` on a holder-bearing master) was removed from this document (BE-owned guard, out of scope for the FE run).
- Every create / delete / race case targets a `QA TC G01 <date>` fixture. If a fixture was consumed earlier, create a fresh one with the same prefix and the next suffix — never substitute a pre-existing master. If that is impossible, mark the case `Block — no fixture`.
