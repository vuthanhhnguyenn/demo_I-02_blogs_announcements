# TC -【Fitness CRM】- [G-03-B2][Campaign Detail - Promotion Codes]

**Unit**: 3 — Campaign Detail: Promotion Codes (per `../test-plan.md`)
**Screen / Route**: `/campaigns/[id]` — プロモーションコード tab (`?tab=promo`, deep-linkable)
**Scope**: the promotion-code tab only — toolbar (search/status filter/issuer filter/result count/CSV export/issue button), the issue dialog, the code table, the summary footer, and the disable dialog.

**Out of scope for this unit** (per the test plan; not expanded here):

- The basic-info tab and the change-history tab (separate units, other agents).
- Single promotion-code detail view, per-code change history, per-member usage — the prototype's tab never calls these operations.
- Phase 2 content — the `割引合計` (discount-total) column and the summary footer's `割引総額` figure, both gated behind `currentPhase === "2"` and excluded from the API.

#### Test data and data policy

- **Campaigns** used: `QA-U5-A`, `QA-U1-A` (from Units 5 and 1). Run Unit 5 first (plan order).
- **Codes cannot be deleted** (no endpoint). Every code the run issues is permanent on the shared backend: use manual codes starting `QATU3…` or descriptions starting `QA-U3-`, keep the number small (about 15 in total, reusing codes across cases — e.g. TC-108 reuses TC-124's), and **disable** leftovers at cleanup; list every code in the run report. Pre-existing codes are read-only (never edit, disable or re-enable them; open dialogs only to cancel).
- **Needs-to-exist** (verify first; missing → `Block` with the precondition): a Staff account bound to one store and a second store (TC-097, TC-103, TC-104, TC-102), a campaign with ≥30 codes (TC-121), a campaign whose codes span more than one page (TC-123), a pre-existing limit-reached code (read-only parts of TC-094 / TC-098 — it cannot be produced without member usage).
- **Run order**: after Units 5 and 2. Inside the unit: issue cases (TC-100–TC-102) → read-only listing / filter / footer / layout cases → edit and re-enable (TC-089–TC-095) → disable / status cases (TC-109–TC-113) → CSV (TC-105–TC-108) → concurrency → TC-114 last (it invalidates a session).
