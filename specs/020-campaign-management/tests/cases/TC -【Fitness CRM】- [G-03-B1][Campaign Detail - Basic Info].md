# TC -【Fitness CRM】- [G-03-B1][Campaign Detail - Basic Info]

**Scope**: Unit 2 of the G-03 Campaign Management Refactor test plan — the Campaign Detail screen's page header, tab shell (deep-link behaviour), the 基本情報 (Basic Info) tab's summary strip, 60/40 layout, all six left-column read-only cards (基本情報 / 割引設定 / 適用条件 / 期間設定 / 自動付与設定 / 紹介キャンペーン特典), and the right column (status panel with stop/resume, 店舗での利用 card, その他情報 card). Route: `/campaigns/[id]` (default tab).

**Out of scope for this unit** (covered by sibling units or explicitly deferred, per the test plan and spec Assumptions — not expanded here): the プロモーションコード tab content and its two dialogs (Unit 3); the 変更履歴 tab content (Unit 4); the actual edit-form field behaviour reached via 編集 (Unit 5 — this doc only checks the entry point exists, is role-gated, and navigates); the 複製 (duplicate) flow (not present as a header action on this screen per the mockup — the List screen's row menu owns it, per Unit 1); the store↔campaign link write surface (store detail's own contract/pricing tab owns it; this screen only reads and cross-links); Phase 2 `discountTotal` content (gated behind `currentPhase === "2"`, removed from scope entirely).
