**Data limitations** (referenced in Notes):

- **L1 — Counts are not fixed.** Other users create / delete controllers on the shared backend; every total is "verify at execution" against the list's own `pagination` total, never a hard-coded number.
- **L2 — Multi-page needs > 25 rows in scope.** 全店舗 (HQ) is expected to exceed 25 controllers; if it does not at execution time, page-navigation cases are **Block (data)** unless the run creates extra `QA-E02-PAGE-<n>` controllers it can clean up.
- **L3 — 異常 / 廃棄 controllers cannot be created** while B3 is open (live enum has no such values). Their cases are Block (B3).
- **L4 — 制御ポート数 = null** cannot be created through the form (required). The `---` cell can only be observed on a pre-existing record that has it — otherwise Block (data).
- **L5 — Staff account flags.** Staff test accounts ship on 職位 `未割当` (0 permission flags). Before Staff cases check `/crm/me`; if equipment flags are absent assign a real 職位 and re-login. Still failing for lack of flags → **Block (account)**, not NG.
- **L6 — Large 3–4 digit tab count** is only reachable if the scope already holds ≥ 100 controllers; otherwise Block (data).
