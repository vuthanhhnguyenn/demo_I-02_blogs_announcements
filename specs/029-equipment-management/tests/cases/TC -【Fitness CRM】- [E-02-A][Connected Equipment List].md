# TC -【Fitness CRM】- [E-02-A][Connected Equipment List]

**Unit**: E-02-A Equipment List (per [../test-plan.md](../test-plan.md) §2, unit 1 of 6)
**Screen**: 接続機器一覧 (Connected Equipment List) — route `/equipment`, plus the shared 店舗機器管理 layout chrome (title, count badges, tab bar, `CSV出力`, `新規登録` menu) and the 一括状態変更 (bulk status change) dialog.
**Scope**: table (12 / 13 columns), keyword search, 詳細フィルター (店舗 / 機器タイプ / 状態), filter result banner, 異常 deep link, sort, pagination, row selection + 一括状態変更 dialog, CSV出力 on the 接続機器 tab, the 接続機器を登録 entry point, role gating and store scope on this screen, layout robustness at 1024px. Since 2026-11-19 also 機器タイプ エリア扉 (`[エリア扉]` cases TC-197…TC-202).
**Out of scope** (test plan §1): the device detail / form (units B, C — only the navigation into them is checked), the 接点制御装置一覧 panel itself (unit D — only the tab navigation and the absence of bulk UI there are checked), the header store switcher as a screen, the dashboard 異常 widget (only the landing of its link), FR-013 利用ログ, E-03 screens.
