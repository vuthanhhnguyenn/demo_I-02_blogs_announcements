# Tasks: Article Category Form (Notice & Blog Management)

## Dependencies & Execution Order

### Phase Dependencies

- **Setup (Phase 1)**: No dependencies — T001 and T002 can start immediately and run in parallel (different files)
- **Foundational (Phase 2)**: Depends on Setup completion — BLOCKS all user stories
- **User Story 1 (Phase 3)**: Depends on Foundational completion — no dependency on US2/US3
- **User Story 2 (Phase 4)**: Depends on Foundational completion and on T010/T011 (US1) since it extends the same `ArticleCategoryForm` component and barrel file
- **User Story 3 (Phase 5)**: Depends on T012 (US1) and T016 (US2) existing as real pages to verify against — but requires zero new implementation code itself
- **Polish (Phase 6)**: Depends on all desired user stories being complete

### Within Foundational

- T001 → T003 → T004 (schema before table `create`, `create` before `update` — same file)
- T001 → T006; T004 + T006 → T007 (same `[id]/route.ts` file — sequential)
- T005, T006, T007 → T008 (generate client only after all three route handlers exist)
- T002 + T008 → T009 (mapper needs both the form schema and the generated body/response types)

### Parallel Opportunities

- T001 and T002 (Setup) — different files
- T011 and T015 — different files, though both depend on T010 having created the component file first for T011, and the folder existing for T015
- T019 and T020 (Polish) — independent tooling runs
