**Data limitations**:

- **Environment (`B1`)**: run on the local BE; dev is v1 until the deploy.
- **Fresh-DB-only states**: the true-empty list (TC-A-052) and the never-saved store URLs (TC-A-085) exist for real only before the first setting / the first store URL save. Run them first; afterwards use the route fake named in the case and write "fake data" in Notes.
- **Time-driven cases (TC-A-080 – TC-A-083)** need one ~5-minute window around R1's start. R1, like F1–F3, can never be deleted afterwards (local only).
- **Count-sensitive cases** use the live total N (baseline + fixtures, also `[Y-05-B]` X\* and `[Y-05-C]` E\* rows if those units ran first), never a fixed number. Paging needs N > 50 — P01–P55 guarantee it.
- **L1's widest value**: if the server refuses `999999999.999999999.999999999` / `2147483647`, use the largest value it accepts and record it.
- **Long staff names** (更新 line) and the **server field-error mapping** the client pre-empts are reachable only by route fake.
- **Delete order**: run the pagination cases before the delete cases (they remove P51–P53).
