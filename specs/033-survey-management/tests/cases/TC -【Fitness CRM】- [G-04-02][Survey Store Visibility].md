# TC -【Fitness CRM】- [G-04-02][Survey Store Visibility]

**Scope**: Unit **U4 — Store visibility** of [`test-plan.md`](../test-plan.md): `/surveys/[id]/visibility` — header-store-driven target store, role notice / all-stores notice, per-question and per-choice switches that save immediately (`PUT …/questions/{questionId}/visibility`, `PUT …/choices/{choiceId}/visibility`), collapse of a turned-off question, last-ON-choice lock, success / failure toasts, in-flight disabling, role × store scope (server-enforced), and the effect on the detail (FR-D02) for the edited store only.
**Out of scope here**: the detail screen itself (U3 — header actions, 店舗別表示設定 button gating and its deny tooltip, exact copy of the scope sentence, disable dialog), the form (U2 — authoring the fixtures, server text limits, reorder), list / responses / analytics (U1 / U5 / U6), the header store selector and sidebar as components (shared chrome, used only as an input), member app rendering of the hidden items.
**Run order**: plan §10 step 4 — after U2 create has produced the `QA-SVY` fixtures, before U2 edit; role cases (TC-030…TC-039) last; the cleanup case TC-079 closes the unit.

### Data limitations

- Toggles are **only** made on `QA-SVY` surveys; pre-existing surveys are opened read-only at most. Every case that turns something OFF ends with a restore step; TC-079 sweeps all fixtures × stores.
- No answers can be created from the CRM: the answered-question path (TC-073) is `Block (B10)` unless an answered `QA-SVY` survey exists.
- Server text limits for name / question / choice are U2's to establish; the long-value fixtures use U2's observed max (fallback: 255, assumed default — confirm with PO/schema owner).
- Replay cases (TC-034, TC-035, TC-037, TC-039, TC-044, TC-045, TC-049, TC-074) need DevTools ("Copy as fetch" of a captured authenticated request, edit URL / body, run in the console). Without DevTools access → `Block (tooling)`.
- ST-C requires the master to hold stores of both brands; if not → TC-031 step 4 and TC-072 `Block (data)`.
