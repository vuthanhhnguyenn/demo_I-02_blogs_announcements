# TC -【Fitness CRM】- [G-04][Survey List]

**Unit**: U1 — Survey list (`/surveys`), per [`../test-plan.md`](../test-plan.md) §2–§5.
**Scope**: page chrome and header actions (回答データ / 集計分析 / 新規登録), search, 詳細フィルター (種別 / ブランド / 状態), `FilterResultBanner`, the 11-column table and its cell fallbacks, server-side sort on 8 columns, pagination and page size, URL state, loading / error / empty states, row actions 編集 / 無効化 (有効 row) and 編集 / 有効化 (無効 row) with role gating, re-enabling a 無効 survey from its row (no dialog, `E-QST-010`, failure), opening the shared disable dialog from a row (confirm, failure, refetch), role × scope incl. server refusal, long-value layout at 1024×768, output escaping.
**Out of scope** (plan §1–§2): the disable dialog's own field rules (reason 500 / 501 boundary, trim details beyond one check, whitespace-only) → U3; the create / edit form → U2 (this doc only uses it to create its `QA-SVY` rows); detail, visibility, responses, analytics screens → U3–U6 (only the navigation into them is checked here); member-detail アンケート回答 tab, member app answering, lifecycle flows that fire a survey, copy / history, Phase 2 features (absence only).
