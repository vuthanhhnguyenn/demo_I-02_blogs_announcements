# TC -【Fitness CRM】- [G-04-A][Survey Analytics]

**Unit**: U6 — Analytics (`/surveys/analytics`), per [`../test-plan.md`](../test-plan.md) §2–§5.
**Scope**: page chrome and entry paths, target-questionnaire resolution (`survey_id` / questionnaire dropdown), filters (期間 / ブランド / 店舗 / 会員区分 / 入会後経過期間 / 性別; the dropdown is a picker, not a filter), KPI cards (総回答数 / 回答率), per-question cards (choice bars, free-text samples, link to the response list), aggregate CSV (`…/aggregate/export`), role × store scope (UI gate and server refusal), real-API states (401, request failure, loading, deep link), long-value layout at 1024×768 and output escaping.
**Out of scope** (plan §1): the detail screen's 集計分析 button gating (U3), the response list / response detail the free-text link opens (U5 — this doc only checks the link target and that the list is scoped), creating answers (member app), the header store selector and sidebar themselves, Phase 2 axes and formats (only their absence is checked).

## Test-data reference

**Run constants** (record at the top of the run): run date **T** (JST) and `<YYYYMMDD>`; backend URL; Staff's 所属 store **S-own** and one other store **S-other**; Manager's 管轄 stores; the 職位 of each account and whether that 職位 has `can_export_survey_csv` (read on the staff-permission screen — **never change** a shared position).

**Notation used in the cases**

- "Analytics" = `/surveys/analytics`. **AGG** = `GET /api/v1/admin/questionnaires/{id}/responses/aggregate`. **EXP** = `GET /api/v1/admin/questionnaires/{id}/responses/aggregate/export`. **LOOKUP** = `GET /api/v1/admin/questionnaires?page=1&limit=1` (default target, no `survey_id`). **LIST** = `GET /api/v1/admin/questionnaires?limit=20[&nameQuery=…][&page=n]` (the dropdown's options, fetched while it is open). "Net" = DevTools › Network.
- **JST midnight** of a date D = `D T00:00:00+09:00` = previous day `T15:00:00Z`; either serialisation is fine.
- **HSCROLL check** = in the console `document.documentElement.scrollWidth > window.innerWidth` must be `false`.
- **Viewport 1024×768** = supported floor, sidebar expanded unless the step says otherwise; **1440×900** = wide check.

### Answer fixture AF (needs the member app — `B10` until it exists)

On SV-CH (activated on the local BE) or, read-only, on any survey that already has answers. Needed: ≥ 6 completed answers spread over **two stores** (S-own + S-other), **two brands** and **two member types**; Q1 picks with distinct counts (e.g. 3 / 2 / 1 → 50.0% / 33.3% / 16.7%) and one choice with 0 picks; Q2 multi-picks; Q3 ≥ 6 free-text answers on distinct dates, one 1,000-char full-width text, one 1,000-char unbroken ASCII text, one `<script>alert(1)</script>` text; **one 辞退** answer; one answer in 先月 and one in 今月 (JST); ideally one submitted at 00:00–00:59 JST on the 1st of 今月 and one at 23:00–23:59 JST on the last day of 先月.
