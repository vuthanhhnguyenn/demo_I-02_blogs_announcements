# TC -【Fitness CRM】- [Y-08-A][Exercise List]

**Unit**: Y-08-A List (per [../test-plan.md](../test-plan.md), unit 1 of 4)
**Screen**: エクササイズ一覧 (Exercise List), route `/exercises`
**Scope**: the list screen only:

- page header (title, count badge, 「CSV出力」 / 「参照マスタ管理」 / 「新規登録」 entry points);
- table columns, row click, keyword search, the 5-filter 詳細フィルター panel, filter result banner, empty / loading / error states;
- column sorting, pagination, URL state;
- row menu: 編集, 公開にする / 非公開にする (with the unpublish confirm), 削除 (confirm + blocked variants, incl. the 409 path);
- CSV export, role gating and the real-API checks for this screen.

**Out of scope** (per the test plan): the detail screen (Y-08-B), the create/edit form (Y-08-C, only that 新規登録 / 編集 route to it), 参照マスタ管理 (Y-08-D, only that the button routes to it), mobile-app visibility of 公開 (B12), Y-09 routines (used only to set up TC-112), E-03 screens, header store switcher, sidebar and login as screens of their own.

Seeded data (read-only): 71 seeded exercises plus the seeded masters. The prototype's sample rows (ベンチプレス, スクワット, デッドリフト, ラットプルダウン, レッグプレス, ダンベルカール, プランク, ケーブルクロスオーバー) illustrate the expected look only; the real seeded set is not knowable from the spec, so every count is **verify at execution**.

**Data limitations** (referenced in the affected cases' Notes):

- **L1. True-empty is unreachable.** Seeded exercises must not be deleted, so TC-078 is recorded **Not run (no data)**.
- **L2. Multi-page conditions.** About 71 rows + run rows give at most 4 pages at 25/page. The ellipsis (TC-086) needs more than 175 rows, so it is **Not run (no data)** unless the data grows. Use a keyword or filter with more than 25 matches for TC-050 and TC-118, chosen at execution.
- **L3. The thousands separator** needs ≥ 1,000 rows, so TC-149 is **Not run (no data)**.
- **L4. Routine fixture.** TC-112 needs a throw-away Y-09 routine. If none can be created, record **Not run (no routine fixture)**. Never attach a test exercise to an existing routine.
- **L5. Shared backend.** Other users create and delete rows, so counts are compared against a fresh reload, never a hard-coded total. A 502/503 during a BE redeploy is re-run, not NG.
- **L6. M1 / M2 from Y-08-D.** TC-145 depends on them. If they were not created, record **Not run (no data)**.

**Cleanup** (end of run): unpublish, then delete every `TC-EX-<ts>-*` exercise; delete the routine `TC-EX-<ts>-R` before F12; leave master cleanup to Y-08-D.
