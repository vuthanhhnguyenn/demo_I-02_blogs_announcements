# TC -【Fitness CRM】- [Y-08-B][Exercise Detail]

**Unit**: Y-08-B Detail (per [../test-plan.md](../test-plan.md), unit 2 of 4 — executed **third**, after Y-08-D create/edit and Y-08-C, per the plan's suggested order)
**Screen**: エクササイズ詳細 (Exercise Detail) — route `/exercises/[id]`
**Scope**: the detail screen and every dialog inside it — header (title / code / status badge / 編集 / 「…」 menu / back link), the three tabs 基本情報 / 解説ステップ / 関連情報, the ステータス card with its 公開 / 非公開 confirm and incomplete-step warning, サムネイル画像 gallery, 動画URL, 紐づけ機材, タグ設定, 関連エクササイズ, the 削除 dialog (published / routine-linked / OK branches), not-found handling, role gating.
