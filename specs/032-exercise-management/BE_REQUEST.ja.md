> エンドポイントはすべて `/api/v1` 配下。TC番号のユニット: A = エクササイズ一覧、B = エクササイズ詳細、C = エクササイズ 登録/編集、D = 参照マスタ管理。

**ステータスの意味**

- **不足**: API またはフィールドが未実装のため、新規追加が必要。
- **更新**: API は存在するが、仕様／PO決定に合わせて拡張またはコントラクト変更が必要。
- **修正**: Swagger/OpenAPI の定義誤り（挙動は正しいが、定義が実態と異なる）。
- **バグ**: 仕様と異なる挙動。API の直接呼び出しで再現できる。
- **削除**: 不要になったフィールドまたはパラメータの削除。
