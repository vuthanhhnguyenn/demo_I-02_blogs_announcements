**Data limitations**

- Shared backend, no reset: counts (`{N}件`) assume nobody else priced the fixture; verify at execution.
- All dates are in 2027 (future) to avoid colliding with live sales and to keep per-date rows disposable.
- **Cleanup at the end of the unit**: delete every QA per-date price on FX-LONG-J / FX-LONG-T / FX-FIT365 except DS-1 if later re-runs want it (or delete all); the default price written by TC-077 cannot be removed — list it in the run log.
- The Manager / Trainer / Observer cases need the stores those accounts can see (record them in unit 1).
