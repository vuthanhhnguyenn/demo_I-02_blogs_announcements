# API Contracts consumed — Y-02 delta (2026-10-02)

Every endpoint already exists in `src/lib/openapi.real.json` (staged regen). This feature declares **no new endpoint**; it is a consumer. Hooks come from `src/lib/api-real/@tanstack/react-query.gen.ts`. The path prefix is `/api/v1`.
