# TC -【Fitness CRM】- [A-01-BL-A][Blacklist List]

**Unit A** of the Blacklist Management test plan — the ブラックリスト管理 list screen (`/members/blacklist`): table, toolbar (search + two filters), filter-result banner, empty states, pagination footer and the 手動登録 entry point.

**Scope**: access control for the list, display of the seven columns, search, the 登録経路 / 未納金 filters, banner and counters, empty states, pagination, loading/error, layout robustness at 1024px.

**Out of scope for this document** (per [test-plan.md](../test-plan.md) §1):

- The 手動登録 Sheet's contents → Unit B (only the button is checked here, FR-034).
- The blacklist detail and the 解除 flow → Unit C (the list is used only as a navigation source and to confirm a released entry is absent).
- The member detail (`A-01-01`) and its BL dialog → verified for navigation intent only / Unit D.
- 照合結果 column, status filter, level, history — not built by decision; their absence is correct (Q-01, Q-02, Q-06, Q-07).

## Test-data reference & limitations

- **Live data is shared and has no reset.** ≈11 active entries exist on dev (≈8 with unpaid > 0, ≈3 with ¥0) — **verify at execution**; never hard-code a total the case didn't create.
- **Pre-existing entries are read-only.** No case here edits, releases or re-registers one. Cases that mutate data use throw-away members with the prefix **`QA-BL-<yyyymmdd>-<n>`** created through the application flow (`POST /admin/applications`, `sbps_credit`) and registered through the Sheet.
- **Volume gap**: the live set is below the smallest page size (25), so multi-page behaviour (ellipses, page clamping, search match beyond page 1, page reset) is written as a **UI-only variant on a route-faked response (PC-E)**; the real-data variant is `Block` — data limitation — when the live total ≤ 25. The blank-slate state needs an emptied backend → also PC-E.
- Variants needed from live data (verify at execution, otherwise Block "variant missing"): a 手動登録 row; a row with unpaid > 0 and one with 0; a row with empty reason categories; a row with no primary store; a 強制退会 row (subject to B2).
